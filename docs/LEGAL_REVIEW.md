# 법률 검토 요청 자료 (나루 우체국)

공개하기 전에 변호사나 개인정보 전문가에게 이 문서를 보여 주고 검토를 받기 위한 자료입니다. 아래는 **서비스가 실제로 하는 일**을 있는 그대로 정리한 것이고, 법적 판단은 담겨 있지 않습니다. 법적으로 필요한 문구가 있는지, 지금 문구가 충분한지는 전문가가 판단해야 합니다.

## 1. 서비스 개요
- 링크로 편지를 보내고 받는 웹 게임. 보내는 사람은 편지(글)와 선택적으로 자기 목소리 녹음을 올리고, 링크를 가진 사람이 열어 본다.
- 로그인 없이(이 기기에서만) 쓸 수도 있고, 닉네임·비밀번호 또는 Google로 가입할 수도 있다.

## 2. 처리하는 정보와 보관
| 정보 | 언제 | 어디에 | 보관/삭제 |
|---|---|---|---|
| 닉네임 | 가입·로그인 시 | 서버 DB | 계정 삭제 시 삭제 |
| 비밀번호 | 이메일/닉네임 가입 시 | 서버 DB(원문이 아닌 scrypt 해시) | 계정 삭제 시 삭제 |
| 이메일(선택) | 가입·계정 설정 시 | 서버 DB | 인증 메일 발송, 비밀번호 찾기에만 사용. 지우거나 계정 삭제 시 삭제 |
| Google 계정 식별자·인증된 이메일 | Google 로그인 시 | 서버 DB | 구글의 이름·사진은 저장하지 않음. 연결 해제·계정 삭제 시 삭제 |
| 진행 기록·편지함 목록 | 로그인한 경우 | 서버 DB(JSON), 이 기기 브라우저 | 계정 삭제 시 삭제 |
| 편지(보내는 사람 이름, 받는 사람 이름, 내용) | 링크로 보낼 때 | 서버 DB | 보관 기간(기본 30일, 최대 90일) 후 자동 삭제, 거두면 즉시 삭제, 계정 삭제 시 삭제 |
| 목소리 녹음(선택) | 동의 체크 후 녹음·전송 시 | 서버 DB(BLOB) | 편지 삭제와 함께 삭제, 신고 시 재생 차단 후 운영자 확인, 올리면 이 기기 사본 삭제 |
| 접속 주소(IP) | 신고·편지 올리기·가입 등 | 해시값만 서버 DB | 신고 중복 방지, 발신자 차단, 호출 횟수 제한. 원문 저장 안 함 |
| 로그인 세션 | 로그인 시 | 서버 DB(토큰의 해시) | 60일 또는 로그아웃 |
| 백업 | 하루 1회 | 서버 디스크 | 최대 14개 보관(삭제한 정보가 백업에 약 2주 남을 수 있음) |

## 3. 외부 서비스(정보가 나가는 곳)
| 서비스 | 용도 | 전달되는 정보 |
|---|---|---|
| Render(호스팅) | 서버·DB 운영 | 위 모든 서버 저장 정보(서버 위치는 서비스 설정에 따름) |
| Google | 로그인 | 로그인 시 Google이 계정 식별자·이메일을 우리에게 전달 |
| Resend(메일) | 인증·재설정 메일 | 수신자 이메일, 메일 내용(링크) |

## 4. 전문가에게 확인할 질문
1. 지금 `/privacy` 안내와 녹음 동의 체크가 개인정보 수집·이용 동의 또는 처리방침 요건으로서 충분한가? 빠진 필수 항목이 있는가?
2. 목소리 녹음은 개인정보(음성 정보)로 보아야 하는가? 별도 동의 방식이 필요한가?
3. 위 외부 서비스(해외 서버 포함)로 정보가 전달되는 점을 어떻게 고지·동의받아야 하는가?
4. 14세 미만 이용자가 쓸 수 있는가? 연령 확인이나 법정대리인 동의가 필요한가?
5. 편지 내용에 제3자의 개인정보·저작물이 들어갈 수 있다. 신고·삭제 절차(현재: 신고 → 녹음 재생 차단 → 운영자 확인·삭제)가 적절한가?
6. 이용약관, 개인정보 처리방침의 별도 문서화가 필요한가? 운영자(사업자) 정보와 문의처 표기 의무는?
7. 백업에 삭제한 정보가 최대 14일 남는 점을 어떻게 고지해야 하는가?
8. 로그 보관(현재 서버가 별도 접속 로그를 저장하지 않으나, 호스팅 서비스의 로그는 별도)에 관한 고지가 필요한가?
